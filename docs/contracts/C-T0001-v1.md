# C-T0001-v1 — Versioned workspace boundary

Producer: T0001. Boundary: `repo`. Version: **v1**, 16 October 2026. Owner-approved trackable allowlist and line-ending policy. Status: submitted for independent review; frozen once T0001 is ACCEPTED.

## Boundary

| Element | Contract |
|---|---|
| Version control | Git, accepted branch `main` on `github.com/yahyaAboamer/Opshub` (private). One branch and worktree per Task ID. |
| Private custody | The 70 protected originals in [workspace-inventory.json](../development/workspace-inventory.json) `private_custody` stay only on the owner's computer (primary workspace) and are absent from all Git history. Rules: `source/`; `evidence/artifacts/text/*.{extracted.txt,blocks.json,pdf-text.json}`; `evidence/artifacts/text/review-page-*.png`; `evidence/live/phase1b/assets/`. |
| Excluded generated | 3 protected `.pyc` caches (`excluded_generated`) plus every `__pycache__/` and `*.pyc` |
| Trackable roots | Files `.gitattributes`, `.gitignore`, `AGENTS.md`, `CLAUDE.md`, `package.json`, `package-lock.json`. Directories `.github/ apps/ docs/ evidence/ ops/ packages/ scripts/ tests/`. |
| Ignored | Private custody; secrets and credentials (`.env`, `.env.*` except `.env.example`, `.npmrc`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `*.keystore`, `*.jks`, `id_rsa*`, `id_ed25519*`, `id_ecdsa*`, `secrets/`, `secret/`); private fixtures (`tests/fixtures/private/`, `*.private.*`); `node_modules/`, `dist/`, `build/`, `coverage/`, `playwright-report/`, `test-results/`, `blob-report/`, `*.tsbuildinfo`; Python caches; `.DS_Store`, `Thumbs.db`, `*.log` |
| Synthetic fixtures | Tracked under `tests/fixtures/` (for example T0006's `tests/fixtures/shared/`) |
| Line endings | `* text=auto eol=lf`. Byte-exact (`-text`) for `docs/{architecture,domain,migration,product,reconstruction}/`, `evidence/` (except `evidence/implementation/`) and `evidence/implementation/phase6-input-baseline.json` |
| Runtime baseline | Node 24 LTS via `package.json` `"engines": {"node": ">=24 <25"}`; `"private": true`; no dependencies, no lockfile. Observed locally: Node v24.16.0, npm 11.13.0 (not a pin; T0002 qualifies and pins). |

## Preconditions and postconditions

- **Precondition:** all 298 protected files match `evidence/implementation/phase6-input-baseline.json` on the owner's computer (AGENTS.md via its recorded amendment).
- **Postcondition (fresh clone):**
  - Every tracked file lies under a trackable root.
  - No private-custody, secret-like or `.pyc` path is tracked or present anywhere in history.
  - Each of the 225 trackable protected files is byte-identical to its baseline digest.
  - All 73 custody and generated files are absent.
- **Postcondition (owner's computer):** all 298 originals unchanged.

## Errors (test assertion → meaning)

| Assertion | Meaning |
|---|---|
| `tracked file outside approved trackable roots` | A root-level file or directory was added without a C-T0001 amendment |
| `private-custody file tracked` / `private or generated path present in history` | Custody breach; needs history repair, not a forward delete |
| `secret-like or generated file tracked` | Credential or cache committed |
| `trackable protected file missing or not byte-identical to baseline in clone` | Line-ending or content drift of a protected input |
| `protected original changed` | An on-disk original drifted |
| `secret/private path not ignored` / `approved trackable path wrongly ignored` | Ignore rules regressed |

## Commands

- `npm run test:t0001` runs `node --test "tests/tasks/T0001/*.test.mjs"` with Node 24's built-in runner and `git`, and no packages.
- `OPSHUB_CUSTODY_ROOT=D:/Desktop/Opshub npm run test:t0001` also checks the on-disk originals. Without the custody root, that check reports NOT_CHECKED.
- `python evidence/implementation/verify_plan.py` is the Phase 6 plan verifier. It accepts outputs inside declared task editable areas, and counts custody files absent from a checkout as `protected_in_private_custody_not_checked`.

## Tenant and transaction assumptions

None. This boundary holds no tenant data and no transactions. Real or customer data must never enter a trackable path.

## Changing this contract

Adding a trackable root, changing ignore or line-ending rules, or moving a file into or out of private custody requires a C-T0001-v2 under the `root-contracts` lock with owner approval. A custody breach requires a history rewrite approved by the owner.
