## Deliberately rejected invariants

- One order equals one shipment; one return equals one reverse leg/call.
- Every Bosta Delivered means kept; Completed means physically delivered; Cancelled excludes RTO.
- Every paid or no-courier order is collected pickup.
- Every call label is a User identity; every Confirmed tag is an actual timestamped consent event.
- No call can precede recorded order date, enforced by repairing evidence.
- Every reported attempt count implies exactly that many historical attempt events.
- Every Refunded/Resolved/Re-shipped field means an executed transaction/action.
- One snapshot per product/week regardless of source/definition/revision, with old evidence destroyed.
- Every ad has exactly one product; generic spend may always be allocated by an assumed zero-sales rule.
- All currency amounts are known EGP; missing fee/spend/refund equals zero.
- All source references are globally unique, all SKUs permanent, all phones unique people.
- A shared User identity automatically grants cross-merchant access; Merchant Membership implies platform administration; platform authority requires membership in every merchant.

Rejected statements are not alternative approved rules. They are known risks or unsupported assumptions preserved by the model. Proposed invariants remain proposals until human review.
