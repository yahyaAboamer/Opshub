## Findings for consumers

1. **No SWC needed.** Vite 8.3.4 transforms with Oxc, which reads `experimentalDecorators` and `emitDecoratorMetadata` from `tsconfig.json` and emits the metadata Nest needs. The stack stays Vitest-only with one transformer.
2. **Vitest 5 `fsModuleCache` must be off** for reproducible results. Its default kept transforms cached across a `tsconfig` change.
3. **`isolatedModules` with decorator metadata:** types used only in decorated signatures need `import type`, and injected classes must be value imports.
