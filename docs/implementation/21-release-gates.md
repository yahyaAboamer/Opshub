# Distinct operational release gates

| Boundary | Exact tasks | Evidence/authority before proceeding |
|---|---|---|
| Local implementation | T0001 onward within selected scope | Human Phase6 plan/local coding approval; current task START gates, accepted interfaces and synthetic environment |
| Actual controlled qualification | T0308/T0405/T0914, T0707–T0710, T1202/T1203 | Separate read/storage/mail/exact-effect envelope, ownership, scoped credentials, no unapproved physical/financial/customer consequence |
| Read-only shadow | T1206 readiness → T1207 operation | Applicable MD01–07/09/11/13/14, source closure/native ownership, full fixture/golden/tenant/privacy/staged recovery/private rehearsal, approved observation/targets; incumbent sole mutation/contact authority |
| First consequential class | T0701 decision → T1301 operation | One selected qualified class, current Merchant Admin, per-class limits/side effects, EA/RV/marker/native unknown recovery, verified conflicting incumbent/native holds and kill switch; explicit first-class permission |
| Broader controlled actions | T1302 | Each supported class independently qualified/approved; coupled native-booking/conflict groups controlled, exact result counts/partial success/fallback reconciled |
| Real external contact | T1303 | Independently retained start-marker/coverage, restored/inherited consumed/uncertain budget, concurrency/current authority, approved timing/no-call rule and verified exclusive contact authority; explicit permission |
| Cutover | T1304 rehearsal → T1305 exact report → T1306 operation | All applicable HC/AC/PC/EA/TI/AU/RV/GD/KR/CT proof, current source closure/seed/repair/privacy/grants, signed ready/held generation/conflict-group/traffic/delta/deadline/abort envelope and distinct cutover approval |

Read-only shadow means zero OpsHub consequential mutation and contact starts at server/worker/provider-egress boundary. A disabled UI button is insufficient. Actual provider qualification may use authorized synthetic nonproduction effects; it does not authorize real pilot operations.

Unknown earlier effect or contact allowance retains its hold. Missing native identity/journal/privacy/seed/repair coverage expands quarantine. Required core booking/replacement and product/ROAS inputs must meet their contracts; unsupported optional actions have exact exception fallback, not invented PASS. No release gate accepts a scalar-only contributor comparison or “all pages returned” as acquisition closure.

G-P6/AUTH-* and current OP/A/MD decisions are canonical in [decision-gates.yaml](decision-gates.yaml). Gate applicability includes environment and stage. Future release decisions do not block unrelated local construction. Their eventual approval cannot waive zero-tolerance correctness.
